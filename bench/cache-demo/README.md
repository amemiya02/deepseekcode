# Cache-Savings Demo

A reproducible A/B that proves deepseekcode keeps DeepSeek's prompt cache hot —
measured from DeepSeek's own `prompt_cache_hit_tokens`, not a screenshot.

## Arms
- **naive** — mutates the system prefix each turn (timestamp/counter), the
  failure mode of generic agents → the prefix is a cache *miss* every turn.
- **stable** — deepseekcode's byte-identical prefix → after turn 1 the whole
  prefix is a cache *hit*.

Both replay the same fixed 12-turn script on `deepseek-v4-flash`.

## Run it
- `make demo-cache-offline` — no key; replays the committed sample.
- `DEEPSEEK_API_KEY=sk-... make demo-cache` — real calls (~pennies; free on the 5M grant).

## Verify the stability claim for $0
`dsc trace inspect TRACE.jsonl` prints `prefixes 1` for a stable run plus the
realized `cache % | saved CNY`.

## Numbers
All ¥ figures come from `internal/llm/cache_metrics.go` (the same table the Cost
HUD uses). `results.json` is regenerated by each run.
